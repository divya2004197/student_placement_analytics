# Student Placement Analytics Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze student placement outcomes and identify key factors influencing employability.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- VS Code

## Dataset
- 45,000 student records
- 15 features

## Dashboard Features
- KPI Cards
- Placement Analysis
- Branch-wise Insights
- Gender Analysis
- Coding Skills Analysis
- CGPA Analysis
- Aptitude Analysis
- Interactive Slicers

## Key Findings
- Higher CGPA correlates with better placement outcomes.
- Coding skills significantly influence placement success.
- Students with internships and certifications perform better.
- Communication skills contribute positively to employability.
